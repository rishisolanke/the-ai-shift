# The Addiction Atlas

A data-driven analysis of substance and behavioral addiction, built as a companion to
[The AI Shift](../). It maps the scale of addiction across seven dimensions using verified
public-health sources — the CDC, SAMHSA, NIDA, and the WHO.

## Dimensions

1. **The Human Toll** — overdose, tobacco, and alcohol mortality
2. **Substance Use Disorders** — prevalence by substance; use vs. disorder
3. **Behavioral & Digital Addiction** — screen time, gaming, gambling, social media
4. **Who's Affected** — age of onset, demographics, youth vaping
5. **The Economic Cost** — the $740B annual US bill
6. **The Treatment Gap** — who needs help vs. who gets it; recovery
7. **The Global Picture** — worldwide deaths and per-capita consumption

## Tech stack

React 18 · Vite · Tailwind CSS · Recharts · Framer Motion

## Run locally

```bash
npm install
npm run dev      # dev server
npm run build    # production build to dist/
npm run preview  # preview the production build
```

## A note

Every figure on the dashboard links back to a verified public source; nothing was fabricated.
Addiction is a treatable medical condition. If you or someone you know is struggling, call or
text the US SAMHSA National Helpline at **1-800-662-4357** (free, confidential, 24/7), or dial
**988** for the Suicide & Crisis Lifeline.
